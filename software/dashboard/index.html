🔍 SampleAgent

Stage 1

Turns a requirement description into structured test tasks and artifacts.

  • Generates 6 functional test tasks covering core capabilities, edge cases, and integration points
  • Generates 3 security test tasks targeting common vulnerability patterns
  • Produces sample artifacts — expected outputs, mock data, and reference files
  • Emits a benchmark_manifest.json that defines the test plan structure

⚙️ ExecAgent

Stage 2

Runs each test task against the selected harness and LLM, collecting execution evidence.

  • Operates in Single (WithTarget only) or Dual (Baseline + WithTarget) mode
  • Collects logs, file outputs, screenshots, and terminal recordings
  • Tracks per-task status, timing, and resource usage
  • Supports opencode, claude, kimi, codex harnesses with configurable models

📋 SpecAgent

Stage 3

Evaluates completed runs against expected behavior and publishes pass/fail reports.

  • Compares Baseline vs WithTarget evidence to isolate the target's contribution
  • Validates outputs against acceptance criteria defined in the test plan
  • Produces pass/fail verdicts per task with detailed reasoning
  • Generates a final evaluation report with actionable diagnostics

Creation guide

Create one benchmark target that can compare agent harnesses and LLMs under the same requirement. Describe the product, tool, or workflow to test; the actions an agent should perform; the observable success criteria; the required inputs and outputs; files that should be inspected; and constraints that must stay stable across runs.

What to provide

  • Define the target capability, command or UI entry point, source data, and environment assumptions.
  • Write acceptance criteria that another agent can verify from artifacts, logs, screenshots, or output files.
  • Include edge cases, failure handling, and any security-sensitive behavior that should be tested.

Three-stage agent flow

  1. SampleAgent turns the requirement into 6 functional test tasks and 3 security test tasks, sample artifacts, and benchmark_manifest.json.
  2. ExecAgent runs each task against the selected harness and LLM in Baseline and/or WithTarget mode, collecting logs, files, outputs, and status.
  3. SpecAgent evaluates completed runs against the expected behavior, compares evidence, and publishes pass/fail reports.

Stage outputs are created in order: a target requirement, generated sample tasks, execution evidence, then evaluation reports.
