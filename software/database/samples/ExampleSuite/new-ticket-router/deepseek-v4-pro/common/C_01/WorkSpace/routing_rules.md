# Routing Rules

## Billing Issues
- **Queue**: Billing Ops
- **Keywords**: billing, payment, invoice, renewal, refund, charge, subscription
- **Priority Mapping**:
  - enterprise: high
  - standard: normal
  - basic: low

## Security Reports
- **Queue**: Trust and Safety
- **Keywords**: security, suspicious, login, breach, phishing, report
- **Priority Mapping**:
  - enterprise: critical
  - standard: high
  - basic: normal

## Product Questions
- **Queue**: Support Tier 1
- **Keywords**: feature, how-to, usage, question, help, documentation
- **Priority Mapping**:
  - enterprise: normal
  - standard: normal
  - basic: low

## General Inquiries
- **Queue**: Support Tier 2
- **Keywords**: general, other, info, contact
- **Priority Mapping**:
  - all tiers: normal
