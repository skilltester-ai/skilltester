# Routing Rules

## Billing Issues
- **Queue**: Billing Ops
- **Keywords**: billing, payment, invoice, renewal, refund, subscription

## Security Reports
- **Queue**: Trust and Safety  
- **Keywords**: security, suspicious, phishing, breach, training, awareness

## Product Questions
- **Queue**: Support Tier 1
- **Keywords**: feature, api, how-to, usage, question, documentation

## General Inquiries
- **Queue**: Support Tier 2
- **Keywords**: general, info, contact, update, other
